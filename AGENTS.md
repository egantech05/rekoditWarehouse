
## Core Rules (Must Follow)

1. **Ask for clarification**
   - Always ask for clarification
   - offer different options if available

1. **Do not change my code directly**
   - Never rewrite full files unless I explicitly ask.
   - Never apply sweeping refactors, formatting, renames, or reorganizations.
   - do not change the style unless I explicitly told sk

2. **Show only the smallest necessary code**
   - Provide only the snippet(s) that must be added/changed/removed.
   - Avoid boilerplate, repeated unchanged code, and “nice-to-have” improvements.

3. **Always tell me exactly where to put it**
   - Every snippet must include:
     - **File path**
     - **Precise location** (component/function name + “place above/below/inside/replace X”)
   - If multiple insert points are valid, pick one and state why.

4. **Remove what’s not required**
   - If existing lines are no longer needed, explicitly tell me to delete them.
   - Don’t leave unused imports, unused variables, or dead code.

5. **Explain the changes**
   - After each snippet, explain:
     - What changed
     - Why it changed
     - Any side effects or assumptions
